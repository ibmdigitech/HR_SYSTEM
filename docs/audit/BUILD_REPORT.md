### Errors Fixed (BUILD-001)

**File**: `app/dashboard/settings/templates/page.tsx:34-36`

```
TS2345: Argument of type '{ ... }[] | undefined' is not assignable to parameter of type 'SetStateAction<any[]>'.
        Type 'undefined' is not assignable to type 'SetStateAction<any[]>'.
TS18048: 'res.data' is possibly 'undefined'.  (line 35)
TS18048: 'res.data' is possibly 'undefined'.  (line 36)
```

**Root Cause**: `getLetterTemplates()` in `app/lib/actions/letter-templates.ts:14-23` returns an un-narrowed union:
```ts
return { success: true,  data: templates };
return { success: false, error: error.message };
```
TypeScript cannot narrow `res.data` from `res.success` because `success` widens to `boolean` rather than the literal discriminant `true`.

**Fix Applied** (`app/dashboard/settings/templates/page.tsx:33`):
```diff
-        if (res.success) {
+        if (res.success && res.data) {
             setTemplates(res.data);
             if (res.data.length > 0 && !selectedTemplate) {
                 selectTemplate(res.data[0]);
             }
         } else {
```

**Runtime Impact**: None. On the success path `res.data` is always a defined array; the added `&& res.data` check is a truthiness guard that is always true there. It only narrows the type.

**Verification**: `npx tsc --noEmit` → 0 errors. `npm run build` → PASS.
